# ProofPitch AI · 2–3 minute demo script

1. **Sign in and establish trust (20 seconds).** Open the local app. On first run, choose **Create the local owner account**. Explain that the workspace is authenticated, local, and requires no paid provider or API key.
2. **Run the safe demo audit (25 seconds).** In **Run a prospect audit**, enable **Use the named offline demo fixture** and submit without a URL. Point out that the UI labels the result `DEMO`; the fixture URL is always `https://demo.proofpitch.local/`.
3. **Inspect observable evidence (30 seconds).** Show the evidence inspector: title, missing meta description, H1s, image alt coverage, links, audit ID, source, and timestamp. Explain that recommendations come from deterministic HTML checks, not invented business facts.
4. **Show the bounded local preview (20 seconds).** Enter a proposed meta description and select **Re-check preview**. Highlight the wording: **Local preview only — no website changes made**. Show the proof record with its local re-check marker.
5. **Manage the prospect (25 seconds).** Select the prospect in the pipeline. Move it from `Audited` to `Proposal ready`. Explain that transitions are server-enforced and that demo records are not counted as real-business analytics.
6. **Show the improvement concept and quote (35 seconds).** Scroll to the local improvement concept. Explain that it is application-owned, editable and clearly separate from observed live content. Enter a currency, one or two line items in minor units, deliverables, exclusions and timeline. Point out the computed total and that prices are supplied by the operator.
7. **Save the evidence-backed proposal (25 seconds).** Select **Review and save proposal**. Show the selected prospect, audit ID, revision, provenance, concept, evidence sources, bounded scope, quotation and next step. Explain that each save creates a historical revision and that opening a proposal is read-only.
8. **Print and refresh (20 seconds).** Open the in-page print view, show the readable concept and quotation, press Escape, then refresh. Point out that the selected prospect and latest evidence remain associated.
9. **Close on honesty (15 seconds).** State that live audits accept only validated public HTTP(S) URLs, failures do not fall back to demo data, quoted amounts are not revenue, and no outreach, contact scraping, payment collection or live website modification is performed.
